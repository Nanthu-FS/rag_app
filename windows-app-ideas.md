# Windows App Ideas

## ⭐ Picked
**Git Repo Dashboard** (built: [`git_dashboard/`](git_dashboard/)): one window showing the status of every local repo: branch, uncommitted changes, ahead/behind remote, last commit. Includes one-click fetch, pull and open in editor.

## More Ideas

### Developer tools
1. **Port & Process Inspector**: see which app is using which port and kill it in one click
2. **Env Variable Manager**: edit, back up and switch sets of PATH and environment variables
3. **Local Server Launcher**: start and stop dev servers, Docker containers and DBs from the tray
4. **Snippet Vault**: searchable code snippets with a global hotkey to paste
5. **JSON/YAML Viewer & Diff**: pretty-print, validate and compare config files
6. **Regex Tester**: live match highlighting with a cheat sheet
7. **Commit Message Helper**: uses a local LLM to write a commit message from the staged diff
8. **Dependency Update Checker**: scans projects for outdated pip/npm packages
9. **SSH Connection Manager**: saved hosts, keys and one-click terminal
10. **Log Tail Viewer**: follow multiple log files with filters and color rules

### Productivity
11. **Clipboard History**: search, pin and sync clipboard items
12. **Screenshot + OCR**: capture a region and copy the text
13. **Focus Mode**: Pomodoro timer that blocks distracting apps and sites
14. **Quick Launcher**: hotkey search for apps, files and commands
15. **Daily Standup Generator**: builds yesterday/today notes from git commits
16. **Window Layout Saver**: save and restore window positions per task or monitor setup
17. **Time Tracker**: automatically logs time spent per app or project

### System utilities
18. **Disk Space Visualizer**: treemap of largest folders and files
19. **Bulk File Renamer**: patterns, previews and undo
20. **Downloads Auto-Organizer**: sorts files into folders by type or date
21. **Startup Manager**: control which apps launch at boot, with impact scores
22. **Duplicate File Finder**: hash-based detection and safe cleanup

### AI / local LLM (reuses the RAG app)
23. **Ask My Docs (Desktop)**: RAG chat packaged as an `.exe`
24. **Codebase Q&A**: point at a repo and ask questions about the code
25. **Meeting Notes Assistant**: local Whisper transcription with Q&A over past meetings
